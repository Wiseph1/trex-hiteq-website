# TREX HITEQ Website

Static website for the TREX HITEQ device shop in Freetown, Sierra Leone.

## Pages

- `index.html` — Home
- `shop.html` — Shop
- `accessories.html` — Accessories
- `repairs.html` — Repairs
- `exchange.html` — Exchange and trade-ins

The site is published with GitHub Pages from the `main` branch, using the
repository root as the publishing source.
